# Governance

CRIC's governance model is specified in
[`docs/CRIC-PRD-v0.1/community/Open-Source-Governance.md`](docs/CRIC-PRD-v0.1/community/Open-Source-Governance.md):
governance principles, governance domains (software, ontology, knowledge, datasets,
models, agents, safety-relevant interpretation are governed separately), roles
(User, Contributor, Reviewer, Domain Reviewer, Ontology Reviewer, Maintainer, Core
Maintainer), maintainer authority, scientific and ontology governance, decision
records, conflict of interest, security governance, safety governance, and project
stewardship.

This file exists at the repository root so GitHub's own tooling and a reviewer's
first pass find it without knowing the PRD folder structure in advance. It is a
pointer, not a copy — the specification above is the single source; nothing here is
duplicated or restated.

For the standards of behaviour that govern all participation, see
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). For how to propose and submit a change,
see [`CONTRIBUTING.md`](CONTRIBUTING.md).
